AgentID Trust Desk · Open Agent Hackathon 2026 · Track 02 “The Agent That Can Explain Why”

Before your company lets a third-party AI agent touch refunds, customer data or payments, Trust Desk investigates it: on-chain identity and reputation (AgentID / ERC-8004 on Monad testnet), your own procurement, incident, CRM and API-gateway data federated through Zetaris, and prior cases in Meterless H-MEM memory, reasoning with NVIDIA Nemotron behind the Meterless Runtime provider contract (these recorded runs used its direct-NVIDIA fallback). Every claim cites evidence; every citation is checked.

What is real and what is simulated

Real: Monad testnet reads (block numbers in each evidence item), NVIDIA Nemotron calls and reasoning, Meterless H-MEM engine (vendored, unmodified, conformance 13/13), the Zetaris REST client and the Lightning SQL in sql/zetaris/, the Meterless Runtime client (tested against a contract stub).
Simulated: these recorded runs used zetaris-sim, a local stand-in that speaks the same Zetaris REST contract over the same views (real Zetaris needs an 8 GB Docker host); no Meterless Runtime was running, so the router logged primary_unconfigured and used NVIDIA directly. The company “Northwind Freight” and its internal records are synthetic demo data (data/internal).
